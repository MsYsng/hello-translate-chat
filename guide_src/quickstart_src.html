ラップトップ1台とスマホで、言葉の違う人とすぐ話せます。
4ステップ、5分で試せます。

こんなしくみです

ラップトップの Chrome が、全員のメッセージを各自の言語に翻訳します。
参加者のスマホはQRコードを読むだけ。アプリもログインも要りません。

用意するもの

  • PCラップトップ（Mac / Windows）と Chrome
  • PyPython
  • SP参加者のスマホ
  • Wiみんなで同じ Wi-Fi
初めてのときだけ：ダウンロードと Python の準備
  • GitHub のページの Code → Download ZIP でダウンロードし、ZIP を開いてフォルダにします。
  • Python がなければ python.org から入れます。Windows ではインストール画面の「Add python.exe to PATH」にチェックを入れてください。

4ステップで始める

  1. 起動する

    フォルダの中の起動用ファイルをダブルクリック。ブラウザに管理画面が開きます。

    Mac は HELLO-chat.command、Windows は HELLO-chat.bat。Mac で開けないときは右クリック →「開く」。

  2. 自分も参加する

    管理画面の チャット画面を開く を押し、名前と言語を選んで 話し始める。

    このラップトップの画面が翻訳役になります。会話中は閉じないでください。

  3. 相手を招く

    画面に出るQRコードを、相手のスマホのカメラで読んでもらいます。相手も名前と言語を選べば参加完了です。

    開けないときは、スマホの Wi-Fi 名がラップトップと同じかを確認。

  4. 話す

    自分の言語で書けば、相手には相手の言語で届きます。

    ラップトップに 翻訳モデルをダウンロード ボタンが出たら押してください。初回だけ、言語の組み合わせごとに1回必要です。

終わったら、管理画面の サーバーを終了 を押します。会話はすべて消えます。

つまずきやすい3つ

スマホで開けないWi-Fi の名前がラップトップと完全に同じか確認。ゲスト用 Wi-Fi なら、スマホのテザリングに全員でつなぎます。
翻訳が止まったラップトップのチャット画面を閉じたり、ふたを閉じたりすると全員の翻訳が止まります。
ボタンが何度も出る翻訳モデルは1回押すと1組ずつダウンロードされます。ボタンが消えるまで押してください。

事前の準備、Claude で翻訳する方法、参加者に見せるカード、困ったときの対処は詳細版にまとめています。
