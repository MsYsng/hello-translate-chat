HELLO

chat · 使い方ガイド

初対面の外国語話者と、ログインなしで翻訳チャットするためのツールです。各自が自分の言語で書くと、相手には相手の言語で届きます。

はじめての方はクイックスタート（図解・4ステップ）へ →

しくみ

ラップトップ1台が翻訳役標準では Chrome / Edge の端末内翻訳で全員分を訳し、翻訳内容は外部に送られません。API キーがあれば Claude で訳すこともできます。
参加者はスマホで開くだけアプリもアカウントも不要。同じWi-FiでURLかQRコードを開きます。
3人以上・多言語もOK参加者全員の言語に訳して届けます。20言語から選べます。

主催者ラップトップ担当の準備

必要なもの

  • Python 3.8 以上が入ったラップトップ（Mac / Windows）と hello_chat.py
  • デスクトップ版の Chrome または Edge（最新版）
  • ラップトップと参加者のスマホが同じWi-Fiにつながれること
Wi-Fiに注意: ゲスト用Wi-Fiやホテル・会場の公衆Wi-Fiは、端末どうしの通信を禁止していることが多く、スマホから開けません。その場合はスマホのテザリングに全員でつなぐと確実です。

イベント前日までに（おすすめ）

翻訳モデルは「日本語→英語」「英語→日本語」のように、言語の組み合わせと向きごとに1回ダウンロードが必要です。1度ダウンロードすれば、そのラップトップの Chrome に残ります。当日に慌てないよう、使いそうな言語は先に準備しておきましょう。

  1. ターミナルでサーバーを起動します。
    python3 hello_chat.py
    表示される Laptop と Phone URL の2つのURLを控えます。
  2. Chrome で http://localhost:8765 を開き、自分の名前と言語を入れて 話し始める。
  3. 同じ Chrome の別タブで Phone URL（http://192.168.…:8765 の形）を開き、準備したい言語で参加します。このタブはスマホと同じ「表示だけ」の参加者になります。
  4. 最初のタブに戻ると 翻訳モデルをダウンロード: … ボタンが出ます。1回押すと1組ダウンロードされ、次の組に進みます。ボタンが消えるまで押してください。
  5. 2つ目のタブの言語を変えて（名前の画面に戻すにはリロード）、ほかの言語でも繰り返します。
参加者の言語の数必要なダウンロード（クリック数）例
2言語2日本語・英語
3言語6日本語・英語・スペイン語
4言語12＋韓国語
5言語20＋中国語

当日の流れ

  1. 起動用ファイルをダブルクリックします（Mac は HELLO-chat.command、Windows は HELLO-chat.bat）。ブラウザで管理画面が開きます。Mac で初回に開けないときは、右クリック →「開く」を選びます。macOS が「受信接続を許可しますか？」と聞いてきたら 許可 を選びます。
  2. 管理画面の チャット画面を開く から Chrome でチャット画面を開き、名前と言語を入れて参加します。管理画面とチャット画面に、参加者用のURLとQRコードが出ます。
  3. 相手にQRコードを読んでもらうか、URLを伝えます（下の「参加者向けカード」を見せてもOK）。
  4. 新しい言語の人が入ってきて 翻訳モデルをダウンロード ボタンが出たら押します。ボタンの下に進み具合（%）が出ます。その間、相手のスマホには「翻訳役のPCで翻訳データを準備しています…」と表示されます。
  5. 終わったら、管理画面の サーバーを終了 を押します。会話はその時点ですべて消えます。サーバーを止めずに会話だけリセットしたいときは チャットを終了 → チャットを開始 を使います。
管理画面について: http://localhost:8765/admin は、サーバーを動かしているラップトップからだけ開けます。参加者のスマホからは開けないので、APIキーや操作ボタンを触られる心配はありません。
会話中は守ってください:
  • 翻訳役の Chrome タブを閉じない・ラップトップをスリープさせない（ふたを閉じない）。止まると全員の翻訳が止まります。
  • localhost のタブは1つだけにする。2つ開くと両方が翻訳役になってしまいます。
  • ラップトップのブラウザでは、必ず localhost のほうのURLを開く。192.168… のURLでは翻訳機能が動きません。
知っておくと安心: ログインがないため、同じWi-FiでURLを知っている人は誰でも参加して会話を読めます。人の多い会場では、使い終わったらサーバーを止めてください。

主催者Claude で翻訳する（オプション）

Anthropic の API キーがあれば、Chrome の代わりに Claude で翻訳できます。直前の会話を踏まえた自然な訳になり、翻訳モデルのダウンロード（上の「1組1クリック」）が要りません。

APIキーを取る（初回だけ）

APIキーは Anthropic の開発者向けサイト Claude Console で作ります。Claude.ai の有料プランとは別のサービスで、利用料も別に支払います。

  1. platform.claude.com を開き、Google アカウントかメールアドレスでサインイン（またはアカウント作成）します。
  2. Billing の Buy credits でクレジットを購入します。API は前払い制で、残高がないと動きません。イベント1回なら少額で足ります。クレジットは返金されず、1年で失効します。
  3. API keys で Create key を押し、名前（例: hello-chat）を付けて作成します。
  4. 表示されたキー（sk-ant- で始まる）をコピーします。表示されるのは作成時の1回だけなので、すぐ下の手順で管理画面に貼り付けます。なくしたら作り直します。
安心のために: Spend limits で月の上限額を決めておくと使いすぎを防げます。キーはパスワードと同じなので、チャットやメール、GitHub に貼らないでください。画面の文言が変わっていたら、公式のAPIキーの取得方法を見てください。

設定する

  1. SDK を入れます（初回だけ）。
    pip install anthropic
  2. 管理画面の「翻訳」で Claude を選び、APIキーを入力して 保存して確認 を押します。キーが使えるかその場で確認されます。「このPCに保存する」にチェックしておくと、次回から入力は不要です（キーはこのフォルダの外に、あなただけが読める形で保存されます）。
  3. あとは「当日の流れ」と同じです。ラップトップの Chrome でも localhost のタブを開いておくと、Claude に接続できないときに自動で代わりに翻訳します。

困ったとき

こんなとき確認すること
スマホでURLが開けない（「このサイトにアクセスできません」）まずスマホの Wi-Fi 設定で、ネットワーク名がラップトップと完全に同じか確認します。似た名前の別ネットワーク（「-guest」「-5G」「-2.4G」など）や、Wi-Fiが切れてモバイル通信になっていることがよくあります。名前が同じでも開けないときは、ルーターが端末どうしの通信を止めています（プライバシーセパレーター）。ルーターの設定でオフにするか、テザリングに全員でつなぎます。macOS のファイアウォールで Python の受信を拒否していないかも確認します。
ずっと「翻訳中…」のままラップトップの localhost のタブを開き、翻訳モデルをダウンロード ボタンが出ていないか見ます。タブが閉じていたら開き直して参加します。
「翻訳役のPC（ChromeかEdge）がまだ参加していません」ラップトップで http://localhost:8765 をデスクトップ版の Chrome / Edge で開き、参加します。
「翻訳できない言語の組み合わせです」その組み合わせに Chrome が対応していません。原文がそのまま表示されます。英語など共通の言語で書いてもらうと届きます。
「接続が切れました。再接続中…」自動でつなぎ直します。スマホの画面ロックやWi-Fiの切り替わりで起きます。続く場合はページを再読み込みし、もう一度参加します（名前は覚えています）。
QRコードが表示されないQRコードの表示にはインターネット接続が必要です。出ないときは画面のURLを相手に伝えてください。
訳が少し不自然端末内の翻訳なので、くだけた表現や固有名詞は誤訳しがちです。短く、はっきりした文で書くと伝わりやすくなります。
