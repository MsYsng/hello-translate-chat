HELLO

chat · quick start

日本語やさしい にほんごEnglish

Talk with people who speak other languages, using one laptop and their phones.
Four steps, about five minutes.

How it works

Chrome on the laptop translates every message into each person's language.
Phones just scan a QR code. No app, no sign-in.

What you need

  • PCA laptop (Mac or Windows) with Chrome
  • PyPython
  • SPEveryone's phones
  • WiOne Wi-Fi network for everyone
First time only: download the tool and install Python
  • On the GitHub page, click Code → Download ZIP, then unzip it.
  • If you don't have Python, install it from python.org. On Windows, tick "Add python.exe to PATH" in the installer.

Start in four steps

  1. Start it

    Double-click the launcher in the folder. The admin screen opens in your browser.

    HELLO-chat.command on Mac, HELLO-chat.bat on Windows. If a Mac won't open it, right-click it and choose Open.

  2. Join on the laptop

    On the admin screen, click Open the chat. Enter your name, pick your language and click Start chatting.

    This laptop window does the translating. Keep it open while you talk.

  3. Invite others

    Have others scan the QR code on the screen with their phone camera. They enter a name and language, and they're in.

    Page won't open? Check the phone is on the same Wi-Fi network as the laptop.

  4. Talk

    Write in your language. Everyone else reads it in theirs.

    If a Download translation model button appears on the laptop, click it. It's needed once for each language pair, the first time only.

When you're done, click Stop server on the admin screen. The whole conversation is deleted.

Three common snags

A phone can't open the pageCheck its Wi-Fi network name matches the laptop's exactly. On guest Wi-Fi, have everyone join a phone hotspot instead.
Translation stoppedClosing the chat window on the laptop, or closing its lid, stops translation for everyone.
The button keeps coming backEach click downloads one language pair. Keep clicking until it goes away.
